# JMeter Assertions and Performance Testing

A collection of Apache JMeter test plans demonstrating functional validation inside performance tests.

## Included

- Response assertions
- JSON assertions
- XPath assertions
- Duration and size assertions
- CSV Data Set Config examples
- JDBC assertion exercises
- Aggregate reporting examples

## Run

Open a `.jmx` file in JMeter GUI for inspection, or run it non-interactively:

```bash
jmeter -n -t Response-Assertions.jmx -l results.jtl
```

## Purpose

Created as part of software-testing training to practise validating correctness alongside load and performance behaviour.
